## 📁 Project Modules

### 01-html-basics
**Focus:** HTML structure and keyboard event handling  
**Projects:** Keyboard-controlled box movement  
**Key Concepts:**
- DOM element selection (getElementById, querySelector)
- Event listeners (keydown, keyup)
- Arrow key navigation (keyCode 38-40 and e.key property)
- Dynamic CSS manipulation
- Position tracking

**Files:**
- `index.html` - Basic HTML structure
- `script.js` - Arrow key handling using keyCode method
- `main.js` - Modern e.key approach with switch statement
- `style.css` - Positioning and styling

**Run It:** Open `index.html` in browser → Use arrow keys to move the box

### 05-css-layouts
**Focus:** All major CSS layout methods  
**Projects:** Four different layout techniques  
**Key Concepts:**

#### Float Layout
- Traditional layout method
- Clear float technique
- Header and two-column design

#### Flexbox Layout
- One-dimensional flexible layout
- Flex properties (flex-direction, justify-content, align-items)
- Order property for reordering
- Responsive adaptation

#### Grid Layout
- Two-dimensional grid system
- Grid template columns and rows
- Grid areas and positioning
- Responsive grid with auto-fit

#### Position Layout
- Absolute and relative positioning
- Z-index stacking contexts
- Transform for animations
- Overlapping elements

**Files:**
- `float/float.html` & `float.css` - Float layout demo
- `flex/flex.html` & `flex.css` - Flexbox demo with order property
- `grid/grid.html` & `grid.css` - 3x3 responsive grid
- `position/position.html` & `position.css` - Positioning demo

**Run It:** Open any HTML file to see different layout techniques

## 🚀 Quick Start

### View Any Project
1. Open VS Code and navigate to this folder
2. Install "Live Server" extension (if not already installed)
3. Right-click any HTML file → Select "Open with Live Server"
4. Browser opens with live reload on file changes

### Study the Code
- Each file has **detailed comments** explaining what it does
- Start with `01-html-basics` and progress through `09-background-styling`
- Read the header comments to understand program purpose
- Check inline comments for implementation details

### Experiment & Learn
- Modify CSS values to see instant changes (Live Server auto-reloads)
- Adjust JavaScript values and test behaviors
- Resize browser to test responsive design
- Open DevTools (F12) to inspect elements
